# 동물농장 휴면과 성장 조각
- 인증된 앱 진입·포그라운드 갱신에서 방문을 기록한다. 첫 방문부터 서버 시각으로 72시간 간격을 확인하고, 방문 기록 쓰기는 30초 단위로 제한한다.
- 마지막 휴면 전환 전에 획득한 배치 개체는 터치 또는 밥으로 복귀한다. 같은 개체를 재차 깨워도 버전은 다시 증가하지 않는다. 첫 기록 이전에는 휴면을 소급 적용하지 않는다.
- 중복 교환은 계정 잠금과 기존 수량 동기화 트리거를 사용한다. 같은 디자인의 마지막 개체, 배치 개체, 성장 이력 보유 개체, 미라클은 보호한다.
- 교환 보상은 일반부터 유니크까지 1·2·4·8·16조각이다. 한국 날짜 기준 계정당 하루 한 번 10조각으로 선택한 개체에 20 XP를 지급한다. 미라클은 대상에서 제외한다.
- V37·V38 적용 후 교환, 강화, 방문, 깨우기 API를 사용할 수 있다. 프론트는 구 서버의 방문 404를 호환 처리한다.
- 수정한 Java 클래스 컴파일, PGlite에서 V1~V38 마이그레이션·성장 이력 보호·일일 차감 한도·휴면 경계·깨우기 재시도 확인. 백엔드 전체 Gradle 및 신규 실제 HTTP 통합 검증은 남아 있다.
