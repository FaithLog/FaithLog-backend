# #278 현재 정원 배경 무료 제공

현재 다섯 배경을 배경 목록 조회와 정원 초기화 시 ON CONFLICT DO NOTHING으로 지급한다. 조회는 인증 확인 후 쓰기 트랜잭션에서 수행한다. 프론트는 기존 owned 응답으로 모두 선택할 수 있고, 별도 앱 업데이트 없이 서버 반영 후 적용된다. 미래 배경은 고정 지급 목록에 포함하지 않는다.

검증: H2 PostgreSQL 모드에서 두 사용자 지급/중복 지급/미래 보상 제외 테스트, PostgreSQL QA에서 목록/5종 보유/4종 변경/재조회/최초 직접 저장 테스트를 추가했다. 로컬 RED 및 전체 test 실행은 Gradle 배포 다운로드 네트워크 차단으로 실행 전 실패했다. GitHub CI에서 PostgreSQL/Flyway 전체 테스트 및 빌드 검증이 필요하다. git diff --check 통과. Docker/PostgreSQL 로컬 미설치. Obsidian 사용자 Vault는 이 환경에 연결되지 않아 기록하지 못했다.

리뷰: 기존 보유 검증과 FK 유지, API 필드/스키마/의존성/뽑기 정책 변경 없음. 인증 전 지급 없음. 새 회원과 기존 회원 모두 요청 시 적용. SQL은 사용자/ID 목록을 바인딩한다.
