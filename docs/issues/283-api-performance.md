# #283 주요 API 성능 개선

사용자 요청: 초기 지급·무료 배경 병합 후 느린 미션 수령과 다른 API의 병목을 개선한다.

- 주간·월간 미션: 상태 조회의 원장 조회 5회 → 1회, 제출/벌금 근거 조회 최대 4회 → 1회. 미션별 날짜 범위 및 권한·계정 잠금·중복 지급 정책은 유지한다.
- 일간 미션: 오늘 세 미션 거래 존재 여부를 한 번에 조회한다.
- 투표 댓글: 작성자별 개별 호출을 중복 제거한 일괄 조회로 교체한다. 삭제 댓글 표시와 기존 비활성 작성자 정책은 유지한다.
- 내 납부 목록: 목록 전체 Entity를 불러 합산하는 대신 DB 집계 1행 + 요청 페이지 Entity만 조회한다. 기존 카테고리/상태/보관기간 필터 및 응답 형식은 유지한다. 월간 별도 요약 API의 동작은 변경하지 않는다.

검증: 미션 실데이터·동시 수령·롤백·권한 회귀, JDBC 쿼리 횟수 예산, 100개 댓글의 작성자 배치 호출, 50개 청구 중 페이지 5개만 Entity 로드 및 합계 일치. CI가 관련 QA 후 전체 test/build/Docker build를 실행한다. 프론트 이슈 #327이 수령 뒤 11개 이상의 GET을 제거한다.

운영 p95/응답시간 수치는 실제 운영 측정 전에는 주장하지 않는다. 로컬 Gradle 플러그인 다운로드 제약으로 Java 테스트는 GitHub CI 결과를 사용한다. Obsidian Vault 미연결로 저장소에 기록한다.
