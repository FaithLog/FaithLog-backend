# 동물농장 방치 자동감소 설계 (#289)

현재는 **순수 도메인 정책과 단위테스트**만 추가됨. 실제 동물농장 API/DB/홈에는 아직 적용되지 않았으므로, 이 PR을 병합해도 운영 유저 상태에는 영향 없음.

| 상태 | 미돌봄 시 감소 | 비고 |
|---|---|---|
| 배부름 | 4시간마다 -3 | 0~100 |
| 청결도 | 6시간마다 -2 | 0~100 |
| 행복도 | 8시간마다 -2 | 0~100 |
| 친밀도 | 마지막 돌봄 48시간 유예 후 24시간마다 -2 | 돌봄하면 유예 타이머 초기화 |
| 건강 | 배부름 또는 청결도 <25인 상태에서 12시간마다 -2 | 건강 0은 기절, 회복 가능 |

* 수치는 임시 밸런스. 이 클래스는 **상태 게이지만** 처리한다. 별도 #291 정책에서 **현재 성장 XP도 감소**할 수 있지만, 진화 단계/누적 획득 XP/소유 캐릭터는 줄어들지 않는다.
* 서버의 마지막 평가 Instant와 누적 경과시간 기준으로 정확하게 계산. 잦은 앱 진입으로 시간 잔여분이 사라지지 않음.
* 매분 Cron 없이 조회 또는 돌봄 시 지연 계산한다. 상태 DB 저장, 개체별 행 잠금, 멱등성, 다중 기기 상태 동기화는 #287 후속 개발에서 구현해야 한다.
* 실제 돌봄 회복 수치, 기절 회복 정책, 건강 악화 알림 및 앱 게이지 연결은 미구현.
* 사용자 클라이언트 시각은 사용하지 않고 서버 시간만 신뢰한다.
* 진화 조건은 #287의 `CompanionGrowthPolicy`에서 건강·배부름·청결도 감소 후 상태를 기준으로 재평가한다.
