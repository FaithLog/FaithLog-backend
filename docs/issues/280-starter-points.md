# #280 최초 기본 1000포인트

사용자 요청: 기존·신규 모든 사용자에게 최초 1회 1000P를 기본 제공한 뒤 develop/main 병합. 기존 배경 무료 제공 #278 포함.

V32 마이그레이션에서 기존 잔액에 1000P를 추가하고 동일 거래 원장 키를 기록한다. 사용자 생성 트리거는 신규 계정에 가입과 같은 트랜잭션으로 1000P를 지급한다. 사용자 생성/지갑/거래 테이블을 마이그레이션 중 잠가 동시 구버전 쓰기 및 가입과의 경합을 막는다. 보안 권한은 기존 정책을 유지하며 함수 실행 권한을 PUBLIC/연결 역할에서 회수한다.

PostgreSQL 검증: V31 기존 지갑 75P → 1075P, 지갑 없는 기존 회원 → 1000P, 신규 회원 → 1000P, 재마이그레이션/이름 변경 시 중복 없음, 가입 롤백 시 지급도 롤백. 기본 1000P만으로 10회 뽑기 및 재요청 중복 차감 방지를 기존 통합 QA에서 확인한다. 미션/출석 QA는 초기 지급액을 별도로 반영한다.

CI에서 새 지급/배경 PostgreSQL QA를 전체 회귀 테스트 전에 실행한다. 로컬 및 CI 결과는 PR 검증 이력에서 확인한다. Obsidian Vault는 이 환경에 연결되지 않아 저장소에 기록한다.
