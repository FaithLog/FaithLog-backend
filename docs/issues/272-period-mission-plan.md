# #272 주간·월간 미션 연결 조사 및 결정 초안

이 문서는 작성 당시의 기존 코드 조사와 추천안이다. 2026-11-12 사용자가 초안 전체 구현을 선택해 아래 기준이 확정되었으며 실제 구현·검증은 272-period-missions.md를 따른다.

## 현재 코드에서 확인한 근거

| 미션 | 포인트 | 사용할 근거 | 주의점 |
|---|---:|---|---|
| 주간 경건 제출 | 100 | weekly_devotion_records.submitted_at, week_start_date | 하루 저장과 주간 임시 저장은 제출 아님 |
| 주간 투표 | 50 | poll_responses + polls + poll_response_options | responded_at은 응답 수정 때 바뀜. 최초 참여 주를 판단하려면 created_at 사용 여부를 결정해야 함 |
| 전주 무벌금 | 50 | 제출된 주간 기록과 PENALTY/DEVOTION_RECORD 청구 근거 | 미제출자는 청구 자체가 없으므로 청구 0건만으로 통과시키면 안 됨 |
| 월간 무벌금 | 200 | 대상 주차의 제출 및 벌금 발생 근거 | 납부 PAID와 벌금 미발생은 다름. 커피·밥 청구 제외 |
| 월간 모두 제출 | 300 | 대상 주차의 submitted_at | 없는 주간 row를 누락 없이 계산해야 함 |

WeeklyDevotionCommandService는 submit=true일 때 submitted_at을 기록하고 벌금을 계산한다. 계산액 0이면 청구를 생성하지 않는다. 월간 요약은 월과 겹치는 주를 조회하고 일별 기록은 해당 월 날짜만 집계한다. 이 요약 방식만으로 월간 제출 보상 귀속을 확정할 수는 없다. CampusMember.joinedAt은 재활성화 때 재설정된다.

## 확정이 필요한 추천 기준

1. 보상은 계정당 미션·기간별 한 번. 활성 캠퍼스의 첫 유효 근거를 지급 기록에 보존한다.
2. 주간 제출은 해당 주차 제출 완료, 주간 투표는 해당 주에 최초 생성한 유효 응답 1개 이상을 근거로 삼는다. 과거 투표 수정만으로 다음 주 참여 보상을 주지 않는다.
3. 무벌금은 대상 주차 제출 완료가 필수이며, 벌금을 납부하거나 면제받은 것은 무벌금으로 간주하지 않는다. 관리자 취소로 오류를 정정한 청구는 별도 분류가 필요하다.
4. 월간 제출 대상은 월요일이 해당 월에 속한 주차로 정한다. 마지막 주가 다음 달까지 이어지면 그 주가 끝난 뒤 월간 보상을 연다. 기존 월간 달력 집계는 유지한다.
5. 신규 가입·재가입자는 온전히 소속된 주/월부터 무벌금 및 월간 모두 제출 대상에 포함한다. 가입 전 기간의 실천을 추정하지 않는다.
6. 진행 중인 주/월의 무벌금 보상은 잠근다. 직전 완료 기간만 수령 가능하게 해 무제한 과거 보상 소급을 막는다. 마지막 주가 다음 달로 이어지는 월은 확정 가능일 기준 기간을 별도 표기한다.
7. 지급 완료 후 관리자 정정으로 자격이 바뀔 경우 자동 음수 잔액/회수는 도입하지 않고 운영 확인 대상으로 남긴다. 실제 회수 정책은 별도 결정한다.

이 초안을 확정한 뒤 mission_claims 스키마, 지급 근거 snapshot 및 기간별 조회/수령 API를 구현하고, 미제출/경계 날짜/신규 가입/캠퍼스 중복/정정/동시 요청을 검증한다.
