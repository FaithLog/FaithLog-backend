# 예수님 미라클 캐릭터

사용자 요청: 제공된 80프레임 에셋 재사용, 미라클 0.01%, 미획득 도감 ?, 시즌 없음, develop 통합. 기존 요청의 10,000P에 0 두 개를 추가한 미라클 판매가는 1,000,000P로 적용한다. 뽑기 비용은 기존 100P를 유지한다.

V31은 카탈로그 1종·MIRACLE 제약·판매가·standard-v2 정책을 추가한다. 기존 v1 추첨 결과와 원장 및 가중치는 보존한다. 이전 동물 가중치에 9999를 곱하고 미라클 13000을 추가하여 전체 130000000 중 13000=0.01%를 구성한다. 동물 각 등급 상대 비율 유지. 권한·지갑 트랜잭션·재시도 키 정책 변경 없음.

프론트와 함께 배포해야 하며 운영 배포는 이번 요청 범위에 포함하지 않는다. 로컬 Gradle 배포본 다운로드가 네트워크 제한으로 불가능하여 전체 Java·PostgreSQL 검증은 GitHub CI에서 수행한다. Projects 및 Obsidian Vault 접근 경로는 제공되지 않았다.
