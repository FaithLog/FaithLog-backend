# #272 단계5~6 사전 구현

사용자가 승인한 비용: 1회100P/10회1000P. DrawPolicy는 가중치 검증·불변 snapshot·SecureRandom 추첨·경계 선택 및 비용 검증을 구현한다. SaleQuote는 마지막1마리 유지·서버 단가·정수 overflow 검증을 구현한다. 정책 테스트5개 작성.

미확정 정책: 프론트 체험 가중치 합계 기준 COMMON54%, UNCOMMON30%, RARE11%, EPIC4%, UNIQUE1%. 체험 판매가는10/15/25/40/50P. 정식 정책으로 자동 승인하지 않으며, 현재 이 값으로 활성 뽑기 pool/판매 API를 등록하지 않았다.

이번 변경은 순수 정책 로직만 포함. 운영 DB 변경 없음. 실제 차감·지급·판매 API 및 원자적 처리·idempotency·결과 기록은 후속 작업이며 아직 미구현.

검증 환경 재점검: javac/gradle 없음. apt-get JDK 설치는 dpkg lock 및 권한 부재로 실패. 컴파일/JUnit 미실행 상태를 유지하며 테스트 통과로 표시하지 않음. 이전 전체 초안도 CI 검증 전이다.
